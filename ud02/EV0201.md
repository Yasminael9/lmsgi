##Enunciado

Crear una lista, lista desordenada y una lista ordenada en una tabla

##Solución

```html

<!DOCTYPE html>
<html lang="es">
	<head>
		<meta charset=utf-8"/>
		<style>table, th, td { border: 1px solid black; }</style>
		<title>Casa Gómez - Menú del día</title>
	</head>
	<body>
		
		<table>
			<caption>Restaurante <b>Casa Gómez</b></caption/
			<thead>
			<tr>
			<th><b>Plato</b></th>
			<th><b>Opciones</b></th>
			</tr>
			</thead>
			<tbody>
			<tr>
				<td><ol><li>Primeros</li></td>
				
				<td><ul><li>Ensalada mixta</li><li>Lentejas <q>de la abuela</q></li><li>Macarrones boloñesa</li></ul></td>
				
			</tr>
			<tr>
				<td><li>Sedundos</li></td>
				<td><ul><li>Carne</li><li>Pescado</li><li>Vegano<sup>1</sup></li></ul></td>

				
				
			</tr>
			<tr>
				<td><li>Postres</li></ol></td>
								<td><ul><li>Flan</li><li><del>Helado</del></li><li>Fruta</li></ul></td>
			</tr>
			</tbody>
			<tfoot>
			<tr>
				<td colspan="2"><sup>1</sup>Puede contener trazas de <u type = yellow>sésamo<u> y <u>frutos secos<u></td>
			</tr>
			</tfoot>
		</table>
	</body>
</html>
```
