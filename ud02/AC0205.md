# AC0205

Yasmina El Masoudi El Aouati

## Enunciado

Montar un código que muestre un texto (una cita en realidad) en forma de bloque preformateado al que acompañará una cita que recoja el nombre del autor en HTML5. Dicho nombre será un enlace a su perfil de cuenta de Github.

## Solución

```html
<!DOCTYPE html>
	<html lang="es">
		<head>
			<meta charset="utf-8" />
			<title>AC0205</title>
		</head>
		<body>
		<p>Y el toro dijo al morrir:<blockquote>"Siento dejar este mundo sin probar las pipas <a href="https://github.com/Yasminael9">Yasmina</a>."</p>
		
		
		
		<p>Hola Mundo</p>
		<p><br></p>
		<p>hola<br>mundo</p>
		</body>
	</html>
```
